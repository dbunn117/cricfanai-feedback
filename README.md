# CricfanAI feedback

Corrections and questions for [cricfanai.com](https://cricfanai.com), a
cricket statistics site computed from [Cricsheet](https://cricsheet.org)
ball-by-ball data.

**Spotted a wrong number?** [Open a stat correction](../../issues/new?template=stat-correction.yml)
with the page URL, the figure shown, and where your expected figure comes
from.

Before filing, check [cricfanai.com/about](https://cricfanai.com/about):
the dataset covers T20 internationals between full-member nations and the
major T20 leagues only, so career totals from other sites will often be
higher. That is coverage, not an error.

The site's source code is in a separate private repository; this one exists
only so anyone can report problems without an account on the site.
